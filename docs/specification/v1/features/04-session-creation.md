# 10.4 Session creation form

- Users **paste PR URLs**, one per line.
- The **prompt is optional**; when present it is layered onto built-in behavior (see 10.6).
- Sessions are **auto-named** from their targets (e.g. `org/repo#12 +2 more — Sep 10`).
- **Duplicate/concurrent sessions are allowed**; each submission is independent.
- The session targets **exactly the PRs provided** (there is no "current PR" in the app flow).
